# UI icons

Interface icons from [Lucide](https://lucide.dev) (ISC), stroked at 1.5px on a 24px grid with round caps and joins. Single ink: files here stroke `#767c9d`; inline them with `stroke: currentColor` (the `el-uicon` class) so they follow the text colour.

- Sit at the size of the text beside them (16px for body and buttons, 14px beside labels).
- Pair with text; an icon alone needs an `aria-label`.
- Need one that isn't here? Take it from Lucide, same stroke. Don't mix in another set.
