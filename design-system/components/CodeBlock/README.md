# CodeBlock

Square code block on `surface-raised` with line numbers in `ink-muted`.

- `code` is a string. `highlight` lists 1-based lines for the `mint-soft` ground (one or two at most); `emphasis` lists words to paint `mint` (the call that matters).
- Light tokenising: keywords `blue`, numbers `cream`, comments `ink-muted`. For a full highlighter, use Shiki's Poimandres theme with these colours.
