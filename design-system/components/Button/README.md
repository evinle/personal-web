# Button

Mono button with `radius-sm`. `variant="primary"` is the mint fill with `on-fill` text, at most once per view; everything else is the outline (`ink-muted` border).

- `href` renders an anchor, otherwise a `button` (with `onClick`).
- `glyph` before the label, `glyphEnd` after it (forward actions use `cod-arrow_right`).
- Labels are lowercase mono, verb or destination first.
