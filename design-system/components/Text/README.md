# Text

Paragraphs in IBM Plex Sans, capped at about 70 characters per line.

- `variant="body"` (default) in `ink`; `variant="lead"` is body size in `ink-muted` for intros and card descriptions; `variant="small"` for captions and footnotes.
- `muted` paints any variant `ink-muted`; `as` changes the element (default `p`).
- Inline children can include Link, InlineCode and coloured spans (`el-pink`, `el-mint`) for numbers.
