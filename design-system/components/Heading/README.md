# Heading

Mono headings in three levels; the editor-style prefix is part of the voice.

- `level={1}` uses `display` for page and post titles (one per page).
- `level={2}` uses `heading` with a cream `## ` prefix; it is the section heading (Section renders one for you).
- `level={3}` is a 16px mono title for cards and sub-sections; `prefix` adds `### `.
- `prefix={false}` drops the marker; pass `id` to link a Section's `aria-labelledby`.
