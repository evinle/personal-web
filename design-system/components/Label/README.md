# Label

Uppercase mono label (`label` type style) for kickers, dates, metadata and table headers.

- Muted by default; `tone` switches to `mint`, `blue`, `pink` or `cream` text.
- `glyph` puts an icon before the text (read times use `cod-history`).
- Write the content in capitals yourself where it is a kicker ("ABOUT"); dates stay as written.
